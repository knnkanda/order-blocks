# オーダーブロック (Order Blocks)

ゲーム感覚で数学を学ぶ、コンセプトシリーズ
落ちてくる数字と演算子のピースで式の行を完成させ、計算の順序（PEMDAS）と、分数の割り算の法則（KCF）を、遊びながら感覚的に覚える落下パズルです。

## 遊び方（学び方）

- 盤面は横9マス。奇数列は数字専用、偶数列は演算子専用なので、完成した行は必ず正しい式になります。
- ピースは［数字］［演算子］［数字］の3タイル。左右に動かして落とし、着地したタイルは列の一番下まで沈みます。
- 行が9マス全部埋まると、計算が始まります。ゲームは止まり、計算だけの画面に切り替わります。
- 計算はPEMDASの順序で、1手ずつ大きなタイルで見せます。途中の式がどう変わるかを目で追うのが、このゲームの学びどころです。
- 計算結果がターゲットと一致すれば行が消えて得点。違えば、正しい結果とターゲットの両方を見せてから、行は灰色に石化して残ります。
- ÷の後ろに分数が来たらKCFの出番です。FLIPボタンを押すとボーナス+50点。押すまで計算は止まって待つので、どこがどう変わるかをじっくり見られます。
- タワーが一番上まで届いたらゲームオーバーです。

## PEMDASとは

計算の優先順位の頭文字です。言わば『計算の文法』で、順序を覚えておくと何かと便利です。

- **P = Parentheses（かっこ）** が最優先！
- **E = Exponents（指数・累乗）** が次
- **M / D = Multiplication（かけ算）/ Division（わり算）** を左から順に
- **A / S = Addition（たし算）/ Subtraction（ひき算）** を左から順に

大事なのは、MとDは**同格**で、左から順に計算することです。AとSも同じです。
『かけ算がわり算より先』ではありません。ここを間違えると、答えが変わります。

例： 1 ÷ 1/3 × 3
わり算とかけ算は同格なので左から計算して、1 ÷ 1/3 = 3、3 × 3 = **9** が正解です。
先に 1/3 × 3 を計算してしまうと 1 になり、間違えます。

数学も英語で覚えた方がよいのでは？ PEMDASは英語圏の子どもたちが使う覚え方で、世界の共通語でそのまま通じます。

※ このゲームのプロトタイプでは、かっこ（P）と指数（E）は対象外です。M/DとA/Sの順序と、KCFに絞っています。

## KCFの法則とは

分数の割り算を、逆数のかけ算に変える法則です。KFCではなく、**KCF**です。

- **K = Keep（キープ）** …… 左の数はそのまま
- **C = Change（チェンジ）** …… ÷ を × に変える
- **F = Flip（フリップ）** …… 右の分数をひっくり返して逆数にする

例： 4 ÷ 2/3 → 4 × 3/2 = **6**

ゲームでは、÷の後ろに分数が並んだ瞬間に計算が止まり、Keep・Change・Flipの3つの動きを特大のタイルで1つずつ見せます。言葉で覚える前に、目で見て覚える仕掛けです。

## このゲームで身につくこと

- ×÷は＋−より先、という優先順位を体で覚える
- 同格の計算は左から、という見落としがちなルールを、間違えるたびに石化した行が教えてくれる
- 分数の割り算を見たら、反射的に逆数を思い浮かべる習慣
